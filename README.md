*Tentang Proyek*
Lovin'Crumb menjual cookies dengan tekstur renyah di pinggir dan lembut di tengah. Website ini berfungsi sebagai profil usaha: memperkenalkan identitas, menampilkan katalog produk beserta harga, dan menyediakan kontak untuk pemesanan.

Proyek mengikuti siklus pengembangan web: kebutuhan → rancangan → implementasi → pengujian → dokumentasi dan pemeliharaan.

*Fitur dan Isi Halaman*
Seluruh konten berada dalam satu berkas index.html dengan navigasi anchor.

*Cara Menjalankan*
Clone repositori:
bash
   git clone https://github.com/anggikmyp/Lovin-Crumb/
   cd lovin-crumb
Buka index.html langsung di browser (klik dua kali), atau jalankan server lokal sederhana:
bash
   # jika memiliki Python
   python -m http.server 8000

Lalu buka http://localhost:8000.
